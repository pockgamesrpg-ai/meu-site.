BLUEVAULT GAMES

Arquivos:
- index.html
- style.css
- script.js

Como usar:
1. Coloque os três arquivos na mesma pasta.
2. Abra index.html no navegador.
3. Para editar, use o Visual Studio Code.

IMPORTANTE SOBRE PAGAMENTOS:
O checkout incluído é apenas visual. Não coloque chaves secretas de Mercado Pago,
Stripe, PagSeguro etc. diretamente no JavaScript do navegador.
Para pagamentos reais, use um backend seguro e um gateway oficial.

IMAGENS:
As áreas dos banners estão prontas. Substitua os blocos de demonstração por imagens
que você tenha autorização/licença para usar.

PARCELAMENTO:
O projeto libera até 10 parcelas no cartão de crédito quando o carrinho contém
5 ou mais itens, equivalente à regra "acima de 4 itens".
